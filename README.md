# Digital Tool Buying Platform
## Description
A modern digital toils buying platform where users can explore, purchase, and manage premium digital products like AI tools, templates, and software services. Built with React for a fast and interactive user experience.
## Technologies Used
- React.js
- Javascript
- Tailwind CSS + DaisyUI
- React Toastify (npm package)
- JSON (for product data use)
## Features
- Responsive design
- Add to cart
- Rating badge
